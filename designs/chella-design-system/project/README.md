# Chella Enterprise Design System

**Chella** (*"C"onfluence · tr"ELL"o · jir"A"*) combines an **Obsidian-grade Evidence Console** with **Spec-Driven Development (SDD)** and **CVD-Safe Data Visualization**.

## 1. Visual Pillars
- **Precision Ledger Cards**: Every Change Request (CR) card surfaces its `Ticket ID`, `BA Status`, `SPEC ✓ / CLARIFY` convergence state, and `SRC n` verified evidence capsule in tabular monospace (`JetBrains Mono`).
- **Four Adaptive Personas**:
  1. `dark` — Obsidian Console (`#0b1020` canvas, `#38bdf8` sky accent)
  2. `light` — Daylight Ledger (`#f8fafc` canvas, `#0284c7` oceanic accent)
  3. `furina` — Salon Solitaire Hydro (`#08142c` deep stage, `#38bdf8` spotlight)
  4. `nahida` — Sanctuary of Surasthana (`#0b1d14` forest canopy, `#4ade80` dendro glow)
- **CVD-Validated Categorical Palette**: Verified with `dataviz/scripts/validate_palette.js` across both Light and Dark surfaces (Machado 2009 Protan/Deutan $\Delta E \ge 8.4$, Normal-vision $\Delta E \ge 19.3$).
